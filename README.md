# DSH 插件使用手册（中文）

> 面向 DeepSeek Harness 桌面端插件的**上手说明**与**实战教程**。
> 按「使用特性」分类，一份文档只讲一个插件，装完能直接照着做。

## 这个仓库解决什么问题

DeepSeek Harness（下称 DSH）的插件生态扩张很快，但大量插件的说明只有英文 README，或者散落在项目站的多个页面里。中文使用者常见的情况是：**装上了，却不知道下一步点哪里、为什么这么点、做完应该看到什么效果**。

本仓库把这些内容补上：安装怎么做、界面每一块是什么、按场景一步步操作、以及"如果没出现预期效果该查哪里"。

## 按使用特性分类

| 类别 | 这类插件解决什么 | 已收录 |
|---|---|---|
| **会话可视化与上下文编辑** | 让"模型这一轮到底看到哪些内容"变成可视、可改、可对比的 | [dsh-thoughtdag（ThoughtDAG 画布）](./thoughtdag-dsh/) |
| 检索与历史索引 | 从本地会话、文件历史里查"这件事以前怎么处理的" | 预留 |
| 媒体生成与编辑 | 图像、视频、音频的生成与批处理 | 预留 |
| 数据与报表 | 结构化数据读写、统计与产出 | 预留 |

收录标准：**能装在 DSH 桌面端、有可复现的上手路径、文档能落到具体操作**。只列名字不给操作的清单，不收录。

## 文档约定

每篇文档里的信息按来源分级，不混着写：

| 标记 | 含义 |
|---|---|
| 📄 **官方文档** | 来自上游仓库 README、官方文档站或插件包内自述 |
| 🧪 **本机实测** | 在 Windows 桌面端实际跑过，标注日期、DSH 版本、插件版本 |
| ⚠️ **未验证** | 文档里有描述，但本文档写作时没有实际验证，照做前请自己确认 |

这条约定是硬性的：宁可写"未验证"，也不把推测写成事实。
