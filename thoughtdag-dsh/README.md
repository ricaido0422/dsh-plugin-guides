# dsh-thoughtdag · ThoughtDAG 画布

> 把 DeepSeek Harness 的会话变成一张**可编辑的思维画布**：问答是节点，**连线即上下文**。
> 你可以改掉模型下一轮会看到什么，而不是只能清空重问。

## 一句话说清它解决什么

线性聊天里，模型每一轮看到的是"前面所有内容一锅端"。想换一条思路，只能重开对话，把之前几十轮的废话一起丢掉。

ThoughtDAG 换了个做法：**把讨论摊成图，用连线决定哪些内容进入下一问**。

| 你想做的事 | 线性聊天里 | ThoughtDAG 里 |
|---|---|---|
| 换个方向问，但不污染主线 | 新开一个对话，上下文全丢 | 从某个回答里选中一句话「探索」，长出一条橙色分支，主线不动 |
| 觉得某条旧结论把模型带偏了 | 没法排除，只能重开 | 断开那条连线，节点还在图上，但不再进请求 |
| 想知道"到底为什么这么回答" | 只能猜 | 展开「将发送」预览，逐条看材料/引用/对话轮次和 token 数 |
| 拿两个版本比一比 | 靠记忆 | 同问题同模型重新生成，版本并排，琥珀色陈旧标记提醒 |
| 整理前的探索过程 | 被自动压缩成一段摘要 | 合并摘要/凝练成副本，原路径保留 |

**唯一法则：连线即上下文。** 把需要的路径接到下一问；断开连线，不必删除之前的探索。📄（上游 README_ZH）

## 它长什么样

装好之后，Harness 侧栏「插件」下方多出 **ThoughtDAG** 一行，点它，画布直接在主栏打开：

```
┌─────────────┬──────────────────────────────────────┐
│ 新建 / 搜索  │  画布菜单（My Canvas）                 │
│ 自定义       │                                      │
│ 自媒体工作台  │      ┌──────┐                        │
│ 定时任务     │      │ 问题 │ ← 节点，双击开侧栏        │
│ 上下文洞察   │      └──┬───┘                        │
│ ThoughtDAG  │         │ ← 连线，决定上下文             │
│ 更多        │      ┌──┴────┐                       │
│             │      │ 回答  │                        │
│ 工作区会话…  │      └──┬────┘                       │
│             │    ┌────┴─────┐                      │
│             │  ┌─┴─┐      ┌─┴─┐   ← 分支/探索       │
└─────────────┴──┴───┴──────┴───┴──────────────────┘
```

画布是**同源挂载**在 Harness 现有 web 服务上的 `/thoughtdag/` 路径下，不另起进程、不另开端口，所以没有跨域问题，也不需要额外登录。📄（插件包 README）

## 功能一览（按使用特性归类）

### ① 编辑上下文（核心）
- 「将发送」预览：把下一次请求拆成材料、显式引用、对话轮次，给出消息数、文件数、估算 token
- 删除连线 / 归档节点 / 在「完整结构上下文」与「摘要引用」之间转换
- `@` 提及已命名节点、从连接点拖到已有节点建立引用
- 上下文指纹与陈旧标记：上游改了，下游回答会被提示重新生成，而不是继续冒充最新结果

### ② 分支探索
- 选中回答中的文字 → 点「探索」→ 长出一条橙色分支
- 原地重新生成（同节点加版本）与新建兄弟节点（并排保留两个答案）
- 按依赖顺序重放，做受控对比

### ③ 材料与阅读
- PDF、Word、图片、Markdown、代码、链接快照等材料节点
- 从所选文字或图像区域提问，保留页码来源
- 材料节点独立成页，可在阅读器里摘句再提问

### ④ 整理与凝练
- 合并摘要 / 合并并删除 / 串联高光
- 把连续无分叉的片段凝练成副本，同时保护决策与转折节点

### ⑤ 会话镜像（Harness 场景最实用）
- Agent 对话地图：把本机 Codex、Claude Code、DSH、Pi 的会话读成图镜像
- 每轮问答→一个节点，tool call / tool result 配成该节点的附件
- 增量追加：原 Agent 继续跑，画布只把新轮次接到链尾，旧节点不动
- 从节点「带去 CLI 实验」或「在 CLI 接续新章」，结果挂回原图

### ⑥ 历史查询（why 层）
- 原生工具 `why_check / why_file / why_find / why_recall`，让 Agent 在改文件前先查这块代码的历史
- `/why <路径|网址|arxiv:id>` 命令，直接从对话里查，不额外发模型消息

### ⑦ 记忆（进阶）
- 偏好、身份两份文档随事实改写；每个主题一份带来源的档案
- 提问时按主题带入回忆，可逐条标价并去掉

> ①②③④⑦ 来自上游功能索引 📄；⑤⑥ 来自插件自述与官方插件手册 📄，本机已实测侧栏入口与画布启动 🧪。

## 安装

**前提**：DSH（DeepSeek Harness）**0.1.2-rc.1 或更新**；桌面版侧栏入口需要 **0.2.0-rc.2 起**。📄

### 方式 A：插件页安装（推荐给不碰命令行的人）

1. 打开 Harness → 「插件」页
2. 搜索 `dsh-thoughtdag`
3. 点安装
4. **重启一次 Harness**（插件只在启动时挂载）

### 方式 B：命令行安装

```powershell
# Windows 桌面端（默认安装路径）
& "D:\Program Files (x86)\DeepSeek\resources\runtime\cli\bin\dsh.cmd" `
  plugin --profile desktop add dsh-thoughtdag@0.5.28
```

三个容易踩的点：

| 坑 | 说明 |
|---|---|
| profile 名写成 `web` | 桌面端跑的是 **`desktop`** profile，写成 web 会装到另一套环境，界面上看不到 |
| 不写版本号 | pnpm 默认压住"发布不满 24 小时"的新版本，会装到前一天那一版；要装当天版本就点名 `@0.5.28` |
| 装完没重启 | 插件只在进程启动时挂载，不重启不会出现入口 |

完整流程、验证方法与配置项见 **[01-安装与配置](./01-安装与配置.md)**。

## 五分钟上手

1. **点侧栏 ThoughtDAG**，画布打开（首次会让你选画布或从示例开始）
2. **在中间输入框提第一个问题**，发送 → 生成一个问答节点
3. **在节点底部继续追问** → 第二个节点和一条连线出现，这条线就是"下一问会带上的上下文"
4. **双击任意节点** → 右侧浮动侧栏打开，输入框上方有「将发送约 … tok · … 条消息」

第 4 步的那一行是整套东西的核心：点开它，你就第一次"看见"模型下一轮会收到什么。

逐场景操作见 **[03-实战：编辑上下文](./03-实战-编辑上下文.md)**。

## 适合谁 / 不适合谁

| 适合 | 不适合 |
|---|---|
| 在一个问题上要反复试多个方向，且希望保留探索痕迹 | 只想要一条问答流水线，不需要分支 |
| 被"上下文太长/被带偏"困扰，想手动控制进入请求的内容 | 期待它自动调度多个 Agent、自动分配权限——它不是 Agent OS |
| 已经在用 Codex / Claude Code / DSH，想把历史会话拿来复盘 | 想要替代 Harness 的聊天窗口——画布是补充层，不是替代品 |

📄 上游明确说明：对话地图"还不是一个自动调度进程、权限和资源的 Agent OS"。
