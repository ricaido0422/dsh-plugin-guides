# 02 · 核心概念与界面

理解三个词就够了：**节点、连线、侧栏**。其余都是在它们之上的操作。

---

## 一、节点（Node）

一个节点 = **一次提问 + 它的回答版本**。📄

节点卡片上有什么：

| 位置 | 内容 |
|---|---|
| 顶部 | 问题、角色、状态 |
| 中间 | 当前回答版本 |
| 底部 | 继续、重新生成、复制、编辑回答等高频动作 |
| 徽标 | 生成模型与生成时间；琥珀色标记 = 该回答早于上游变化，需要检查 |

**双击节点**进入完整侧栏；**右键节点**是低频操作菜单（重新生成、概括成便签、复制、CLI 接续、复制副本、归档、删除）。📄

缩小时节点会自动降级显示，三档语义缩放：

```
完整卡片  →  收获句「门牌」  →  图标级标记
（能读全文）   （只看结论句）      （只看结构）
```

放大到完整卡片才能读回答全文，这一档也是做精细编辑时的常用倍率。

---

## 二、连线（Edge）——整套东西的核心

**连线不是装饰，是上下文开关。** 模型下一轮看到什么，由连到你的那些入边决定。📄

四种线，各有含义：

| 线型 | 名称 | 携带什么 |
|---|---|---|
| 紫色实线 | 对话路径 | **完整的上游对话路径**：一路上去的所有问答 |
| 橙色实线 | 探索分支 | 从选中文字长出的独立分支，主线不受影响 |
| 紫色虚线 | 摘要引用 | 只带入指定节点的问答与上游问题线索，**不**把每个上游回答都塞进请求 |
| 红色虚线 | 随动评审 | 评审/诊断类节点，跟随被评对象更新 |

三种改变上下文的手段（都会告诉你 token 差多少）：

| 操作 | 结果 |
|---|---|
| **删除连线** | 这条路线不再进入请求，**两端节点都还在** |
| **归档节点** | 内容保留在图上，但被排除在遍历之外 |
| **转换线型** | 在「完整结构上下文」与「摘要引用」之间切换 |

> 记住一句话：**删线 ≠ 删内容。** 被排除的探索仍然在画布上，随时可以重新接回来。📄

---

## 三、侧栏（浮动侧栏）

双击节点打开，覆盖在画布右侧，**不会挤压或移动节点**；左边缘可拖宽，双击边缘恢复默认。📄

| 功能区 | 作用 |
|---|---|
| 顶部状态与操作 | 角色、token、材料状态，节点级快捷操作 |
| 问题 | 阅读或编辑当前问题；等待输入的节点也在这里填 |
| 回答与版本 | 读完整回答、切换版本、看生成模型，从所选文字继续探索或高亮 |
| 附件 | 加材料，控制"继承附件"是否进入当前上下文 |
| 高亮 | 全文/重点/仅传高亮三种方式，并能从高亮继续提问 |
| 汇入顺序 | 多条上游汇入时，调整它们进入请求的先后 |
| 上下文树 | 按材料、引用、对话检查当前节点真正收到的内容与估算 token |
| 底部追问 | 继续当前路径，输入框上方就是「将发送」摘要行 |

---

## 四、「将发送」——把黑箱打开的那一行

侧栏输入框上方有一行小字：

```
将发送约 1.2k tok · 8 条消息
```

点开它会展开预览，把下一次请求拆成三部分：**材料、显式引用、对话轮次**，并给出消息数、文件数、估算 token。📄

这是判断"为什么模型这么答"的第一现场。养成一个习惯：**换模型、换提示词之前，先看一眼这行数字有没有变**。

> 注意：它只预览"侧栏里这一次追问"，不是整个画布的总账。

---

## 五、上下文是怎么被编译出来的

不需要背实现细节，但知道规则能少踩坑：📄

1. 从你提问的节点出发，**沿入边向上游**找相关节点；
2. 按依赖顺序排序，组成发给模型的消息；
3. 显式引用、开启的材料、启用的回忆再补充进来；
4. 输入框里 `@` 提到的节点，作为显式引用加入。

由此得到两条实用推论：

- **两条平行分支之间没有连线，就不会互相污染。** 这正是"同一张画布放多个 Agent 会话"安全的原因——它们只是摆在一起，不是连在一起。
- **想省 token，就把实线换成紫虚线（摘要引用）。** 上游回答不必整段进入请求，只带问答与问题线索。

## 六、界面里其他值得先认识的

| 位置 | 是什么 |
|---|---|
| 左上画布菜单 | 切换画布、进入 **Agent 对话地图** |
| 右上模型选择器 | 新节点的默认模型；每个节点可单独钉模型 |
| 工具栏 | 模型、重放、分区、搜索、语言、备份、更多操作、撤销/重做 |
| 小地图 / 缩放控件 | 大图导航 |
| 「更多操作」菜单 | 批注显隐、排版、高亮/材料总览、凝练、诊断、分享、导出、外观、记忆、教程 |
| 快捷键 | 滚轮/捏合缩放；中键或右键平移；触控板可在 ⋯ 菜单打开「滚轮平移画布」 |
